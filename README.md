# inkwell

A point-and-click adventure game framework for Go, built on
[Ebitengine](https://ebitengine.org/): scenes, hotspots, verbs, inventory,
dialog trees, cutscene scripts, a widget HUD and themes, declared as plain
struct literals.

```bash
go get git.teletypegames.org/engines/inkwell
```

**Documentation:** <https://wiki.teletypegames.org/godoc/inkwell/latest/> —
the manual and the API reference, built from the package comments on every
release tag.

**Example game:** the `inkwell-demo` repository,
<ssh://git@git.teletypegames.org:2222/demos/inkwell-demo>.
